RUN IN INTELLIJ IDEA ULTIMATE:
1. Add net.sf.saxon:Saxon-HE:12.5 (or a newer 12.x version) as a Maven library
   in Project Structure > Libraries. Include its transitive dependencies.
2. Ensure Saxon is available ahead of the JDK's built-in XSLT 1.0 processor
   on the module classpath, as described in the assignment instructions.
3. In Run > Edit Configurations > XSLT, select report.xsl as the stylesheet
   and orders.xml as the input; select the module with the Saxon library.
4. Set the output to report.html and run. Open report.html in a browser.

The graduate/bonus features require Saxon; the built-in XSLT 1.0 engine cannot
run this XSLT 2.0 stylesheet. Keep both catalog files beside report.xsl because
document() resolves those relative paths against the stylesheet location.
The report has embedded CSS and needs no network connection to display.

OPTIONAL COMMAND-LINE RUN:
With Java on PATH and the Saxon-HE and XML resolver dependency JARs in lib:
  java -cp "lib/*" net.sf.saxon.Transform -s:orders.xml -xsl:report.xsl -o:report.html
Dependencies are external runtime tools; they are not submission files.

IMPLEMENTED:
- Summary and detail views use two apply-templates passes and an order mode.
- Both views sort orders by ISO date, oldest first.
- Product and category lookups use the supplied XML namespaces.
- All prices and totals use tt:money, which calls format-number.
- Stock warnings use xsl:if when the line quantity exceeds product stock.
- Each order shows the sum of its quantities and its decimal money total.
- Dates are formatted as English month/day/year; current-date() supplies the
  generated date, which changes when the transformation is run on another day.
- xsl:for-each-group produces category revenue from all ordered line values.
  Values include requested quantities even when a line exceeds stock.
